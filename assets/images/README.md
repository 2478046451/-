## 学校概况实拍图暗色适配

- 12 张实拍图统一放在 `school/`，HTML 中按顺序引用；轮播容器保持 4:3，图片使用 `object-fit: cover` 居中裁切。
- 图片原生 `filter`：亮度 `0.92`、对比度 `1.05`、饱和度 `0.9`。
- 图片容器 `::after` 叠加深蓝渐变蒙版：`linear-gradient(180deg, rgba(15, 23, 42, 0.25), rgba(15, 23, 42, 0.55))`，正常混合。
- 蒙版写在每个 slide 上，随幻灯片 opacity 一起淡入淡出；底部导航、四角装饰与悬浮上浮效果不受影响。
- 参数集中在 `css/style.css` 的 `.overview-carousel`：`--overview-photo-brightness`、`--overview-photo-contrast`、`--overview-photo-saturation`、`--overview-mask-top`、`--overview-mask-bottom`、`--overview-mask-rgb`。

## 压缩说明

- 12 张学校概况实拍图原始合计约 1.75 MB；处理时保留原 JPEG 量化表，仅做 `optimize`、`progressive` 与元数据清理，合计约 1.68 MB，画质视觉无损。
- 校园生活三张实拍图（`campus-1/2/3.jpg`）合计约 0.61 MB；同样保留原 JPEG 量化表，仅做编码优化，不改变画面内容。
- 院系专业四张实拍图（`college-1/2/3/4.jpg`）合计约 0.89 MB；尺寸与文件对应关系见上表，插入 16:9 图片插槽时按中心裁切。
- 如后续替换实拍图，建议先控制到单张 800 KB 以内，再按同一套 CSS 蒙版与 filter 参数预览亮度。
- 图片含平台水印的版本仅用于本次概念站演示；正式参赛或对外发布前，请确认所有图片素材均拥有合法授权，并在作品说明文档的“素材与数据来源”中列明出处。

## 替换方式

1. 将图片按上表命名，放入对应目录（学校概况图片放入 `assets/images/school/`）。
2. 刷新 `index.html`，图片会自动淡入，插槽提示会隐藏。
3. 页面针对缺失图片做了容错：没有放入图片或路径错误时，会保留占位容器，不会出现布局塌陷。校园生活三张图片现在已放入 `assets/images/campus-1/2/3.jpg`。
4. 院系专业四张 `college-1/2/3/4.jpg` 已提供，分别对应通信与信息工程学院、计算机学院、艺术传媒学院、数字经济商学院。
5. 正式发布前请确认所有图片素材均拥有合法授权；校徽与实拍图由团队提供，Hero 背景为 AIGC 辅助生成。

## 视觉一致性建议

- 主色调：深灰黑背景（`#05080d`）、科技青蓝（`#69f2ff`）、少量低饱和暖金（`#cbb18a`）。
- 学校概况实拍图依赖 CSS 的深蓝蒙版与亮度微调融入暗色页面，请勿再提前把图片压成纯黑或重度调色。
- 建筑与人物素材需确保主体清晰；避免出现可识别的真实个人或伪造的官方标识。
